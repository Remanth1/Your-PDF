# Monetization strategy (payments disabled)

This project will operate without direct payment integration. The following monetization ideas are retained for future consideration but are not implemented:

## Free tier

- Ads on public pages
- File size limits (e.g., 50 MB)
- Rate limit to X conversions/day

## Premium features (future)

- No ads
- Increased file size (e.g., 2 GB)
- Priority job queue
- Batch conversions
- Access to OCR

## Ad model

- Use client-side ad slots (Google AdSense / alternative) on free pages
- Respect privacy: no tracking on conversion pages; show non-personalized ads if needed
